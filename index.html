XInjector State Tools

A comprehensive suite for creating, visualizing, and analyzing XInjector state machine workflows. Choose the tool that fits your needs.

State Builder

Create new state machine workflows from scratch with a visual drag-and-drop interface. Configure entities, conditions, and actions to build complex automation workflows.

Features

  • Visual workflow builder
  • Entity database integration
  • Real-time preview
  • Export to JSON format
  • Biome and dungeon templates

State Visualizer

Upload and analyze existing state JSON files. Visualize workflow structure, analyze node relationships, and understand complex state machines.

Features

  • Upload existing JSON files
  • Interactive graph visualization
  • Node and link analysis
  • Statistics and metrics
  • Export modified states

Both tools work with XInjector state machine JSON format. Use the Builder to create new workflows and the Visualizer to analyze existing ones.
